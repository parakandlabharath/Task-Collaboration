# 🚀 TaskFlow

TaskFlow is a simple website where teams can work together, assign tasks, and track project progress in real time.

## 📝 What is this project?
When working in a team, it is easy to forget deadlines, lose track of who is doing what, and mix up communication. TaskFlow fixes this problem. It gives your team one single place to organize all daily work. 

The website takes complicated group projects and turns them into simple, visual boards. Whether you need to assign a task to a teammate, set a deadline, or check what work is already finished, TaskFlow helps everyone stay on the same page.

### ✨ Key Features
* **Visual Task Boards:** Move tasks easily through different columns like "To Do", "In Progress", and "Done".
* **Live Updates:** See changes instantly when a teammate updates a task, preventing double work.
* **Deadlines & Priorities:** Set clear due dates and mark tasks as Low, Medium, or High priority so the team knows what to do first.
* **Team Roles:** Control who can edit the project by inviting people as Admins, Workers, or Viewers.
